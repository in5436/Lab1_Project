# Аналіз апаратних компонентів: Server Rack Health Monitor

Проєкт реалізується у віртуальному середовищі Wokwi на базі мікроконтролера NUCLEO-C031C6. Нижче наведено аналіз реальних фізичних сенсорів, поведінка яких емулюється базовими компонентами Wokwi для виконання поставлених задач. 

Поточна конфігурація середовища:
*   **USART2** (PA2/PA3) — для виведення логів.
*   **GPIO Output** (PA5) — індикатор стану (LED).
*   **I2C1** (PA9/PA10) — шина для акселерометра.
