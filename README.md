# Server Rack Health Monitor

Навчальний проєкт студента Лазінька Романа, група ІО-36, з курсу «Системне програмування вбудованих систем».

**Ідея:** Система моніторингу стану серверної стійки. Фіксує відкриття дверцят (кінцевий вимикач), температуру всередині (аналоговий термодатчик) та вібрацію/удари корпусу (IMU MPU-6050).

Наразі реалізовано базовий фундамент для ЛР 1: налаштовано мікроконтролер STM32C031C6 (STM32 HAL), підготовлено ізольовану збірку через Docker, перевірено роботу USART2 (лог `tick`) та GPIO (блимання LED). Логіка опитування датчиків буде додана в наступних ітераціях.

## Збірка (Build)

Для компіляції проєкту потрібні встановлені `Docker` та `make`. У корені проєкту виконайте:

```bash
make build
```

Команда автоматично збере Docker-образ із необхідним ARM-тулчейном та скомпілює прошивку. Готові файли (`firmware.elf`, `firmware.hex`, `firmware.bin`) з'являться у папці `firmware/build/`.

Для очищення згенерованих файлів використовуйте команду `make clean`.

## Запуск у Wokwi

Оскільки робота виконується без фізичної плати, для симуляції використовується Wokwi.

1. Відкрийте папку проєкту у VS Code зі встановленим розширенням Wokwi Simulator.
2. Натисніть `F1` та оберіть `Wokwi: Start Simulator`.
3. Файл `wokwi.toml` автоматично підтягне зібраний `firmware.elf`. У вбудованому терміналі ви побачите лог часу (`tick`), а на віртуальній платі почне блимати світлодіод.
